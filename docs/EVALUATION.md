# Evaluation Methodology

- **In-Scope Set**: 62 hand-annotated, paraphrased technical questions across NumPy, Pandas, Matplotlib, Scikit-learn, SQL, and PyTorch.
- **Out-of-Scope Set**: 24 out-of-domain questions to calibrate the refusal gate.
- **Metrics**: hit@3, hit@5, Mean Reciprocal Rank (MRR), Refusal Precision/Recall.
